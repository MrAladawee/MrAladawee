## 📌 Pet-проект: Мультимодальный анализ и прогнозирование

### **📈 Мультимодальная архитектура для анализа новостей и прогнозирования котировок (BERT + LSTM + FiLM)**

Этот проект является основой моей магистерской диссертации и представляет собой полнофункциональную систему прогнозирования.

#### Ключевые элементы:
* **Анализ текста**: Извлечение текстовых признаков из новостных потоков.
* **Прогнозирование**: Прогнозирование лог-доходностей финансовых временных рядов.
* **Архитектура**: Использование **FiLM-модулей** для динамической адаптации признаков текста к временным рядам. Дообучение **RuBERT** + собственная **LSTM-архитектура**.
* **Инженерия**: Проработка требований, **тестирование системы**.
* **Деплой**: Внедрение в **Telegram-бота 24/7** (парсинг каналов, API, обновление данных).
* **Web**: Разработка сайта и серверной части (в процессе).
